# Changelog

## [0.2.1] - 2026-09-09

First public release of XSD Tree Viewer.

- Interactive, read-only XSD previews for Visual Studio Code.
- Lazy expansion and cross-file resolution for large schemas such as UBL.
- Source navigation, filtering, keyboard navigation, and copyable XPaths.
- Namespace-qualified names, attributes, cardinality, documentation, CCTS
  metadata, type lineage, and restriction details.
- Recursive and repeated-type handling with bounded expansion.
- Explorer context-menu support for opening an XSD preview.
