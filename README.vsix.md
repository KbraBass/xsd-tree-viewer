# XSD Tree Viewer

Explore XML Schema files as a readable, interactive tree in Visual Studio Code.

## Use

1. Open an `.xsd` file.
2. Run **XSD Tree Viewer: Open Preview**, or right-click the file in the
   Explorer and choose **XSD Tree Viewer: Open Preview**.
3. Expand nodes to inspect nested elements, attributes, types, documentation,
   restrictions, and source locations.

The preview supports UBL-style namespace prefixes, lazy expansion, recursive
schemas, repeated types, copyable XPaths, filtering, and keyboard navigation.

[Install or review the extension on the Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=KbraBass.xsd-tree-viewer).

Report issues in the [GitHub repository](https://github.com/KbraBass/xsd-tree-viewer/issues).
